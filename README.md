# Mithaq AI ⚖️🇸🇦

Mithaq AI is a Saudi Legal-Tech platform that analyzes and localizes foreign employment contracts to comply with Saudi Labor Law and Qiwa regulations using a Multi-Agent AI workflow.

## 🚀 Features
- Detects non-compliant clauses
- Estimates legal and financial risks
- Rewrites problematic clauses
- Generates Saudi-compliant Arabic contracts

## 🤖 AI Workflow
1. Auditor Agent  
2. Risk Actuary Agent  
3. Legal Drafter Agent  
4. Final Contract Writer & Validator  

The system uses RAG and validation steps to improve accuracy and reduce hallucination.

## 🛠️ Tech Stack
- LangFlow
- OpenAI / LLMs
- RAG
- React
- Node.js
- Replit

## 📌 Prototype & AI Workflow
The current frontend acts as an interactive prototype that simulates the intended user experience and workflow of the final platform.

The actual AI orchestration, agent reasoning pipeline, RAG integration, and validation logic are implemented separately within the LangFlow environment used during the live demonstratio
